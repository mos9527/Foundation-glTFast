# Foundation-glTFast

A fork of https://github.com/atteneder/glTFast with extra glTF extensions defined in https://github.com/mos9527/Foundation-Blender-IO

Installation by Git URL is recommended.

Extra extensions. These can be also found at https://github.com/mos9527/Foundation-Blender-IO
